| 控制循环运动执行 | 67 项检查，覆盖跟踪/到位失败、Action 结果、取消、逐关节服务、方向/偏置、标定保存加载及既有保护 |

2026-10-04 的闭环与程序接口已通过真实 Jazzy 构建、18 项 colcon 汇总测试，以及生产节点配合虚拟 PTY 的 6 项原生服务/Action 集成测试。离线 CTest 5 组共 242 项检查通过；记录见 [闭环与接口验证](validation/2026-10-04-control-interface-checks.json)。虚拟电机验证接口和主机状态机，实际负载下的跟踪精度仍需实机验证。

API 替代头文件用于离线回归。原生服务/Action 测试另外使用真实 rclcpp/rclpy、DDS 与虚拟串口。2026-10-02 的 [GitHub CI 基线](https://github.com/chenzy-pixel/humanoid-robot-control/actions/runs/36926500038)已通过；其[验证证据](validation/2026-10-02-github-ci.json)包含当时被测提交、检查步骤与源码哈希。本轮本地验证结果见上面的 2026-10-04 记录。

运行命令见 [测试说明](../tests/README.md) 和 [运行指南](运行指南.md)，部署前填写 [硬件配置](硬件与控制映射.md)。

2026-10-02 的 [轨迹验证结果](validation/2026-10-02-motion-checks.json)记录当时的 CMake 构建、五组 CTest、七项启动测试及 62 个文件的源码快照；该快照属于当日基线。当前闭环、标定和程序接口的本地真实 ROS 2 验证已完成，实际电机与负载验收仍需执行。
