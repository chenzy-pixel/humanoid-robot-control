# 代码验证范围

本机离线验证与目标 Linux 集成验收分别记录，迁移记录见 [ROS 2 迁移检查](ROS2迁移检查.md)。

| 检查 | 范围 |
| --- | --- |
| 仓库结构 | Markdown 链接、必需文件、ROS 2 package/launch、默认硬件确认、行尾和凭据模式 |
| C++ 协议/传输 | 69 项检查，四型号量程、运控 ID、反馈过滤、300 μs 调度、CRC 和分片 |
| C++ IO | 23 项检查，真实传输源码配合替代 Linux 系统调用 |
| ROS 2 配置与退出 | 35 项检查，拒绝缺失、错类型、重复和越界配置及无效运动限值，禁止未确认使能，验证停止和关闭 |
| 多关节运动规划 | 42 项检查，真实 Ruckig、关节映射、同步、导数连续性、密集运动限幅采样、取消、重定时和曲线越界 |
| 控制循环运动执行 | 40 项检查，模拟反馈下的独立目标、状态发布、轨迹拒绝、输入/反馈超时、超速、故障、发送失败和循环超时 |
| Python launch | 7 项检查，默认值、模式、重定时、参数类型、SDL 选择、重发和退出联动 |
| Linux 系统接口 | 使用实际串口头文件交叉编译 |
| 真实 ROS 2 | Jazzy CI 已通过真实 colcon 构建、9 项 rclcpp 参数测试及安装入口检查 |
| 实机集成 | 目标机 colcon 构建、USB 透传、手柄映射、电机响应与时序仍需验收 |

API 替代头文件用于离线回归，不证明真实 rclcpp ABI、DDS 通信或调度表现。CI 的真实参数测试在配置校验或日志打开阶段结束，不访问 CAN 设备。当前 [GitHub CI](https://github.com/chenzy-pixel/humanoid-robot-control/actions/runs/36926500038) 已通过；[验证证据](validation/2026-10-02-github-ci.json)包含被测提交、检查步骤与源码哈希。

运行命令见 [测试说明](../tests/README.md) 和 [运行指南](运行指南.md)，部署前填写 [硬件配置](硬件与控制映射.md)。

多关节轨迹功能的本机 CMake 构建、五组 CTest 和七项启动测试已通过，记录见 [轨迹验证结果](validation/2026-10-02-motion-checks.json)。构建在 ASCII 路径中的源码快照进行，62 个源码/构建文件与当前工程哈希一致。上面的真实 Jazzy CI 记录属于轨迹加入前的基线；新增功能的真实 ROS 2 和实机验证仍需在目标 Linux 环境执行。
