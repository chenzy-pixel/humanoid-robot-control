# 硬件与控制映射

实际控制配置由 ROS 2 参数文件 `config/motors.yaml` 加载，位于 `can_motor_controller_node.ros__parameters`。`motor_names` 列出活动条目，`motors.<名称>` 保存每条配置。当前文件展示四种型号混用的填写格式，所有接线和机械限位均需依据实际装配逐行填写。

已确认：RS00/RS02/RS03/RS04 都使用；板卡为 SOULDE USB2CAN（经典 CAN），运行于 Windows 中的 Linux 虚拟机。板卡 CAN 速度为 1 Mbit/s，通道为 1/2。虚拟机内使用 `/dev/USB2CAN*` 或实际透传后的 `/dev/ttyACM*` 路径；Windows 原生 Python 调试可用 COM8。设备号对应哪一个实际板卡仍需按接线填写。

| 配置字段 | 含义 |
| --- | --- |
| device | USB2CAN 设备 0 或 1，可在 device0/device1 设置路径 |
| channel / id | CAN 通道 1/2，电机 ID 1～254 |
| model | RS00、RS02、RS03、RS04，分别决定报文量程 |
| min_position / max_position | 关节机械限位，单位 rad |
| neutral_position | 非手柄电机的目标及启动中立位置，必须在限位内 |
| direction | 手柄方向，浮点数 1.0 或 -1.0 |
| kp / kd | 实际物理增益，按该电机型号量程编码 |
| follow_joystick | 是否跟随手柄轴 |

协议范围不等于机械限位。四种型号的速度/力矩/Kp/Kd 量程不同；混用时每个 ID 都必须填写正确型号。当前代码不自动推断电机型号。

使能前还需记录实际设备序列号、固件版本、零点定义、线序、终端电阻、手柄型号以及关节的允许速度/力矩。可删除未接电机，重复设备/通道/ID 配置会被拒绝。

ROS 2 的 SDL 手柄设备用编号或名称选择。通过 `ros2 run joy joy_enumerate_devices` 与 `ros2 topic echo /joy` 核对实际输入映射。
